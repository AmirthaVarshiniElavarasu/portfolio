Quiz Master V2

Quiz Master V2 is an API-first quiz platform built with Flask-RESTful, SQLAlchemy, Vue.js, Bootstrap and Chart.js. It offers role-based access for admins and students, timed attempts with automatic evaluation on submit, and Chart.js analytics summarising per-subject performance. REST endpoints are consumed by a Vue single-page app.

The system also includes background workers powered by Redis + Celery for handling automated tasks like sending reminders, generating reports, and caching data for better performance.
